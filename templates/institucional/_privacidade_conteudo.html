Política de Privacidade

{{ app_name }} — {{ app_tagline }} · Última atualização: {{ ano_atual }}
Este texto é um modelo inicial de política de privacidade, pensado para o contexto do {{ app_name }}. Antes de usar com clientes de verdade, recomendamos que você (ou a locadora que estiver usando o sistema) revise este conteúdo com um advogado, para garantir conformidade com a LGPD (Lei Geral de Proteção de Dados) e com a realidade específica do seu negócio.

1. Quem somos

O {{ app_name }} ({{ app_tagline }}) é um sistema de gestão para empresas locadoras de veículos, desenvolvido por {{ developer_name }}. Cada empresa que utiliza o {{ app_name }} opera sua própria instalação do sistema, com seu próprio banco de dados.

2. Quem é o responsável pelos dados

A empresa locadora que contrata e opera o {{ app_name }} (a "Locadora") é a responsável pelo tratamento dos dados pessoais de seus próprios clientes, motoristas e demais titulares inseridos no sistema — ou seja, é ela quem decide quais dados coletar, para quê e por quanto tempo mantê-los. O {{ app_name }} atua apenas como fornecedor da ferramenta (operador), sem acesso direto aos dados inseridos pela Locadora em sua própria instalação, salvo quando prestando suporte técnico mediante solicitação.

3. Quais dados são tratados pelo sistema

Dependendo do uso, o {{ app_name }} pode armazenar:

  • Dados de clientes/locatários: nome, CPF, RG, CNH e validade, telefone, e-mail, endereço;
  • Informações sobre verificação de antecedentes (se o campo foi preenchido pela Locadora);
  • Dados financeiros relacionados às locações: valores cobrados, pagos, em aberto ou em atraso;
  • Dados de veículos: placa, renavam, chassi, e fotos tiradas durante as vistorias;
  • Dados de usuários do sistema (funcionários da Locadora): nome, e-mail e senha (armazenada de forma criptografada).

4. Finalidade do tratamento

Esses dados são usados exclusivamente para viabilizar a operação da Locadora: gerar contratos de locação, controlar pagamentos e inadimplência, registrar vistorias dos veículos, calcular o score de clientes e dar suporte à administração da frota.

5. Armazenamento e segurança

Os dados ficam armazenados no banco de dados da própria instalação da Locadora. Recomenda-se manter senhas fortes, ativar contas de usuário individuais para cada funcionário (em vez de compartilhar login) e manter backups periódicos do banco de dados e dos arquivos enviados (contratos e fotos de vistoria).

6. Compartilhamento de dados

O {{ app_name }} não compartilha os dados inseridos pela Locadora com terceiros. Eventual compartilhamento de dados de clientes com seguradoras, despachantes ou outros parceiros é de responsabilidade exclusiva da Locadora, conforme sua própria política e as autorizações obtidas de seus clientes.

7. Direitos dos titulares de dados

Nos termos da LGPD, os titulares dos dados (clientes da Locadora) têm direito a solicitar acesso, correção, exclusão ou portabilidade de seus dados pessoais. Essas solicitações devem ser direcionadas diretamente à Locadora responsável pelo atendimento, que é quem detém e administra esses dados.

8. Alterações nesta política

Esta política pode ser atualizada periodicamente. A versão vigente estará sempre disponível nesta mesma página.

9. Contato

Dúvidas sobre esta política podem ser direcionadas ao responsável pela Locadora que administra o sistema, ou ao desenvolvedor do {{ app_name }}, {{ developer_name }}.
